## Archive narration flow (S0–S2)

```
archive video → B01 Intake → B02 Media Prep (proxy · audio · clips · out-of-body flag · overlay masks)
surgeon → 🎙 N1 step template → N2 ★ marks + stop-before-decision clips → N3 Question Engine → voice answers
→ 👂 B06 ASR (2 engines) → B07 who spoke (narration = 1 speaker) → B08 privacy filter
→ 🧠 B09 moments (★-anchored) → B10 card drafter (quote-anchored, AI fills structure only)
→ B26 validators + cross-family verifier → B11 term mapper (danger zone never auto · laterality rules)
→ confidence bands + dedupe → ✅ B12 one review queue → approved card_version 🔏
→ 📚 B14 graph (derived) · B15 index (graph + lexical + dense) · B16 patterns → manual · search · B18 Prepare (S2)
```

## Choice: drafting timing in narration

- **As you go, reviewed at the end of the session (chosen).** Each ★ answer (20–60 s of audio) is transcribed and drafted in the background (≈ 1–2 min), so drafts are ready to review in the same sitting while memory is fresh. A batch re-run is the fallback.
- *Option considered:* batch after the session.
